# AGORA

안국약품 HCP 디지털 플랫폼 화면 구현. 기획 원본은 Notion `AGORA / 01. 기획 · Planning`.

## 실행

```bash
npm install
npm run dev   # http://localhost:3000/vod
```

## 구현 화면

| 화면 ID | 화면명 | 경로 |
|---|---|---|
| H-03 | VOD 목록 | `/vod` |
| H-04 | VOD 시청 | `/vod/[id]` |
| CM-01 | GNB (회원 유형별 메뉴) | 공통 |
| CM-02 | 디지털 MR 우측 패널 (골격) | 공통 |

- 데이터는 목업(`src/lib/vod-data.ts`), 시청 진도·북마크는 localStorage(`src/lib/vod-store.ts`)
- GNB 우측 `의료진 / CMR` 토글은 데모용 회원 유형 전환. CMR은 VOD 메뉴 비노출, URL 직접 접근 시 안내 화면

## Notion 미결 사항에 대해 적용한 기본값

| 항목 | 적용 |
|---|---|
| 필터 레이아웃 V1 / V2 | V1(탭 + 아이콘 그리드) + 접이식 상세 필터(기간·재생시간·연자) |
| 목록 로딩 방식 (H-03-04) | 더보기 |
| 진료과 칩 ↔ 질환 분류 | 병존. 병원경영 탭에서 진료과 칩 숨김 |
| 시청 완료 / 포인트 적립 기준 | 완료 90%, 포인트 50% (+100P) |
| 구간 건너뛰기 (H-04-06) | 허용. 진도는 실제 재생 구간만 집계 |
| 목록 복귀 | 분류·필터(URL 쿼리)·스크롤 위치 유지 |
| 디지털 MR 캐릭터 | 구체(orb)형 자리표시 |
